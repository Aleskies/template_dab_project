📖 API Endpoints

GET /health

Health check endpoint to verify the application status.

curl -X GET https://your-app-url/health

GET /model-info

Get detailed information about the loaded model.

curl -X GET https://your-app-url/model-info

POST /predict

Make predictions using the loaded ML model.

curl -X POST https://your-app-url/predict \ -H "Content-Type: application/json" \ -d '{"feature1": value1, "feature2": value2}'

Expected Response:

{ "prediction": [result], "timestamp": "2024-01-01T12:00:00", "model": "{{ model_name }}", "version": "{{ model_version }}" }
